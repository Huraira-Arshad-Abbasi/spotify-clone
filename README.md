# spotify-clone

A Spotify-style music player UI built with HTML, CSS and JavaScript.

## Features

- Song list rendered from a JavaScript array
- Play / pause, next and previous controls
- Seek bar that tracks playback position
- Active song is highlighted in the list
- Automatically plays the next song when one finishes

## Note on the audio

The tracks in songs/ are short generated placeholder tones, not real music.
The original files were full-length MP3s that made the repository too large to
push to GitHub, so they were replaced with small clips that demonstrate the
playback controls. Drop your own files into songs/ and update the paths in
script.js to use real tracks.

## Made with

HTML, CSS and vanilla JavaScript.
